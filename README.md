# キャラ人格調律工房（Persona Tuning Workshop）

AIチャットアプリ向けのキャラクター人格を、スライダーで「具体的な行動規則」に変換する設計ツールです。

- 公開ページ：https://nyuriwossan.github.io/persona-tuning-workshop/
- 単一HTML・外部AI API不要・登録不要（設定はブラウザ内に保存）
- iPhone Safari 優先

## できること

1. **人格調律**：人格項目（23軸）はすべて任意。最上部の一覧か各カテゴリの中で使う項目にチェックを入れ（新規は全項目OFFから）、選んだ項目だけを 5段階のスライダーで調整する。使っていない項目は控えめな色の行で並び、いつでもチェックできる（外しても値は残る）。「初期」「信頼成立後」「関係深化後」を設定し、変えたくない軸は固定できる。口調プリセット（8種）と一人称・二人称も設定。
2. **人格プリセット**：基本人格12種（高慢・尊大、クーデレ、ツンデレなど）と愛情スタイル8種（甘々、溺愛、無口な溺愛など）。適用前に「今の値 → 提案」を確認でき、使用中で値が違う項目は既定で今の値を残す。固定中の項目は変えない。基本人格と愛情スタイルは別の項目を変えるので重ねて使える。関係での変わり方（徐々に軟化／大きなギャップ／変化は控えめ）を選べ、直前の適用は取り消せる。
3. **関係段階の作り方**：自動提案（初期から後の2段階を一度だけ提案）／連動調整（初期を動かすと段階差を保って追従）／完全個別。
4. **関係・反応**：信頼が成立する／深まる／後退する条件、恋愛感情（信頼とは別軸）、If-Then の行動規則。
5. **人格の試着**：12の状況で、3段階の会話例を並べて比較。口調・呼称を試しに変えられる。会話例は Markdown で書き出せる。
6. **Markdown出力**：上部の「出力先」で、共通Markdown（従来）／Talelynx／チャチャ／Plaitoon を切り替えられる（v0.5.0）。予定文字数に合わせて詳細度を自動選択。共通部分は一度だけ、段階の変化は差分で書く。出力するのは選んだ人格項目だけ。プリセット名は標準では出さず、今の値から作った行動規則を出力する。
   - 出力する節を選べる：話し方・呼称／基本人格・核・3段階の振る舞い／関係の進展条件（初期→信頼成立後・信頼成立後→関係深化後・後退の3種を個別に）／恋愛感情の条件・反応／If-Then（規則ごとにも選択）。新規は話し方と人格だけON。OFFでも設定は保持する。
   - 未設定の行（条件0件など）や空の見出しは出力しない。各節の横に、今の詳細度での増減字数を表示する。

## 出力先の切り替え（v0.5.0）

人格は共通、出力はサービス別です。人格を一度設計すれば、「Markdown出力」画面の出力先を切り替えるだけで、各サービスの欄・字数上限・数え方に合わせて取り出せます。出力先を切り替えても、人格の数値・段階・固定・優先度・呼称・関係の条件・If-Then・予定文字数は変わりません（人格の入力画面にサービスごとの違いは持ち込んでいません）。初期値は「共通Markdown」で、従来の出力と同じです。

### 対応サービスと文字数上限

| 出力先 | 出力欄 | 上限 | 計数方式 |
|---|---|---|---|
| 共通Markdown | 人格設定 Markdown | 予定文字数のみ | 1文字＝1字 |
| Talelynx | 詳細設定 | 7,000字 | 1文字＝1字 |
| チャチャ | 登場キャラクターのプロフィール＋説明（合計） | 2,000字 | 全角1字・半角0.5字（暫定） |
| チャチャ | 会話例 | 25件・合計1,500字 | 同上 |
| Plaitoon 1:1ベーシック | 作品設定および情報 | 8,000字 | 1文字＝1字 |
| Plaitoon シミュレーションベーシック | 作品設定および情報 | 8,000字 | 1文字＝1字 |
| Plaitoon クリエイターカスタム | 設定本文（システム指示） | 10,000字 | 1文字＝1字 |
| Plaitoon（通常テンプレート） | 会話例 | 最大3組・各メッセージ約200字 | 1文字＝1字 |

- **サービス上限と予定文字数は別に管理します。** 例：チャチャ（上限2,000字）で予定文字数1,500字・実際1,420字なら「サービス上限内かつ予定文字数内」と表示します。出力先を変えても予定文字数は書き換えません。予定文字数が未設定（0）のときはサービス上限だけを使います。
- 詳細度の自動選択は、予定文字数とサービス上限の両方に収まる最も詳しい詳細度を選びます。最小でも収まらないときは、最小の詳細度で出力して警告します。**人格の項目を自動で削ったり要約したりはしません。**
- 見出し・Markdown記号・空白・改行・変数表記もすべて数えます。画面の表示と上限判定は同じ計数関数（`countChars` / `countChacha`）を使っています。

### 各サービスの使い方

- **Talelynx**：「詳細設定」欄に貼ります。会話例の専用欄は確認できていないため、使うときは詳細設定の本文に含めます（字数に算入）。
- **チャチャ**：人格を「登場キャラクターのプロフィール」に出力します。「説明」欄は世界観や状況のための欄なので、人格データからは作りません。必要なときだけ出力先の入力欄に自分で書くと、プロフィールと合わせた合計2,000字で判定します。会話例は別枠（最大25件・合計1,500字）です。
- **Plaitoon**：テンプレートを選びます（初期値は1:1ベーシック）。通常テンプレートは「作品設定および情報」欄向けで、会話例は独立欄（最大3組）です。クリエイターカスタムはベースのシステム指示がないため、先頭に「人格に関する指示」の短い前置き（{{char}}として{{user}}と会話する、という1文）を付けられます（OFFにもできます）。独立した会話例欄はなく、使う場合は本文に含めます。
- 出力欄が複数あるときは、欄ごとにコピー・保存できます。コピーされるのは、画面の出力欄に表示されている文字列そのものです（字数表示や案内は含みません）。

### 会話例の扱い

1. 「人格の試着」の各段階の「会話例に追加」（または「この状況の3段階をすべて会話例に追加」）で、使いたい会話例を集めます（最大60件）。
2. 出力画面（Talelynx・チャチャ・Plaitoon）の「会話例」で、出力に含めるかを選び、ユーザー発言とキャラクター応答を別々に編集・コピーできます。編集しても人格データには影響しません。
3. 出力先の件数・組数の上限を超えた分は「対象外」と表示し、削除はしません。合計字数の超過・約200字超のメッセージは警告します。
4. 試着の会話例は外部AIを使わない簡易テンプレートです。**ユーザー発言は空欄で追加されます**（ツールが作らないため）。必ず内容を確認・編集してから使ってください。
5. 本文に含める出力先（Talelynx・Plaitoonカスタム）の話者表記は、Plaitoonカスタムが「{{user}}：」「{{char}}：」、Talelynxが「ユーザー：」「キャラクター名：」です。

### 仕様の確かさと制限事項

2026年11月3日時点の記録です。サービス側の仕様は変わることがあります。

- **上限値・欄の構成は、開発の依頼文書に記載された値を実装したものです。実装時に、各サービスの公式ページとの照合はできていません**（公式ページを取得できませんでした）。変更・誤りがあれば、`index.html` の `SERVICES`（欄・上限・会話例）と `COUNTERS`／`CHACHA_COUNT_RULES`（計数方式）だけを直せば反映されます。
- **チャチャの「半角0.5字」は利用者報告にもとづく暫定仕様**で、公式の現行仕様文書では未確認です。半角の範囲（ASCII・半角カナなど）、改行（0.5字として計算）、絵文字（コードポイントごとに1字）、端数の扱い（切り上げ・切り捨てはせず、0.5字単位のまま判定）は推定を含みます。実機の表示と一致するかは未検証のため、「完全一致」とは表示していません。実機と照合する場合は `countChacha` の結果と比べてください。
- Talelynx・チャチャのユーザー変数の書き方は確認できていないため、変換していません（{{char}}・{{user}}のままです）。貼り付け後に実際の編集画面で確認してください。Plaitoonは {{char}}・{{user}} を使います。
- チャチャの「会話例 25件」が「ユーザー発言と応答の組」なのか「発言1つ」なのかは未確認です。このツールでは、ユーザー発言＋応答を1件として数えています。
- 人格Markdownの書式本体は、どの出力先でも共通です（言い回しや構成を出力先ごとに最適化する機能は未実装）。出力先ごとに変わるのは、出力する欄・上限・計数方式・前置き・会話例の扱いです。

## 愛情の示し方（v0.4で4軸に分割）

| 軸 | 内容 | 区別する項目 |
|---|---|---|
| 言葉による愛情表現 | 好意や感謝を言葉にする度合い | 行動による愛情表現 |
| 行動による愛情表現 | 手助けや気遣いで示す度合い | 言葉による愛情表現 |
| 甘やかし度 | 相手を喜ばせ、世話を焼く度合い（相手の意思や自立は無視しない） | 甘え・頼り方（自分が相手に頼る） |
| 特別扱い | その相手にだけ態度を変える度合い | 独占志向・嫉妬の表出 |

恋愛感情を持たない設定では、親愛・友情の範囲として出力します。どの軸も触れ方（身体の距離）は強めません。

## 使い方

画面右上の「使い方」から、手順とコツを確認できます。

1. 予定文字数を決める
2. 使う人格項目を選ぶ（またはプリセットから始める）
3. 口調と呼称を決める
4. 段階（初期／信頼成立後／関係深化後）ごとにスライダーで調律し、変えない芯は固定する
5. 関係・反応の条件を決める
6. 人格の試着で会話例を確かめる
7. Markdownを出力して、AIチャットのキャラクター設定欄に貼る
8. ときどきJSONで控えを取る

## データの互換性

- v0.1〜v0.3 のJSON・ブラウザ保存データを読み込めます。ブラウザ保存の旧データは、移行前の内容を別名で控えてから変換します。
- v0.3 の「愛情表現」は、言葉・行動の2軸へ推定で変換し、使用・固定・優先度を引き継ぎます（意味が完全に一致するとは限りません）。甘やかし度と特別扱いは初期値・未使用です。元の値はデータ内（`legacy.affection`）に残します。
- v0.3 以前のデータは「完全個別」で引き継ぎ、自動提案や連動は有効にしません。
- v0.4.2 以前のデータ（保存データ・JSON）は、出力先を「共通Markdown」にして読み込みます（データ形式6）。人格データには触れません。ブラウザ保存の旧データは、移行前の内容を別名で一度だけ控えます。新形式のJSONに含まれる未知のフィールドは削除しません。
- v0.4 以前のデータは、出力する節・種類・If-Then規則をすべてONで引き継ぎます（v0.4.1から「（未設定）」の行は出力しません）。

## 注意

- 創作支援のためのツールで、心理検査ではありません。
- 会話例は外部AIを使わない簡易プレビュー（テンプレートの組み合わせ）です。組み合わせによっては不自然な言い回しになることがあります。
