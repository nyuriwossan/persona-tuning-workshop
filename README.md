# キャラ人格調律工房（Persona Tuning Workshop）

AIチャットアプリ向けのキャラクター人格を、スライダーで「具体的な行動規則」に変換する設計ツールです。

- 公開ページ：https://nyuriwossan.github.io/persona-tuning-workshop/
- 単一HTML・外部AI API不要・登録不要（設定はブラウザ内に保存）
- iPhone Safari 優先

## できること

1. **人格調律**：最上部で使う人格項目を選び（新規は全項目OFFから）、選んだ項目だけを 5段階のスライダーで調整。「初期」「信頼成立後」「関係深化後」を個別に設定し、変えたくない軸は固定できる。口調プリセット（8種）と一人称・二人称も設定。
2. **関係・反応**：信頼が成立する／深まる／後退する条件、恋愛感情（信頼とは別軸）、If-Then の行動規則。
3. **人格の試着**：8つの状況で、3段階の会話例を並べて比較。口調・呼称を試しに変えられる。会話例は Markdown で書き出せる。
4. **Markdown出力**：予定文字数に合わせて詳細度を自動選択。共通部分は一度だけ、段階の変化は差分で書く。出力するのは選んだ人格項目だけ（選択を外しても設定データは消えない）。

## 使い方

画面右上の「使い方」から、手順とコツを確認できます。

1. 予定文字数を決める
2. 使う人格項目を選ぶ
3. 口調と呼称を決める
4. 段階（初期／信頼成立後／関係深化後）ごとにスライダーで調律し、変えない芯は固定する
5. 関係・反応の条件を決める
6. 人格の試着で会話例を確かめる
7. Markdownを出力して、AIチャットのキャラクター設定欄に貼る
8. ときどきJSONで控えを取る

## 注意

- 創作支援のためのツールで、心理検査ではありません。
- 会話例は外部AIを使わない簡易プレビュー（テンプレートの組み合わせ）です。
