# キャラ人格調律工房（Persona Tuning Workshop）

AIチャットアプリ向けのキャラクター人格を、スライダーで「具体的な行動規則」に変換する設計ツールです。

- 公開ページ：https://nyuriwossan.github.io/persona-tuning-workshop/
- 単一HTML・外部AI API不要・登録不要（設定はブラウザ内に保存）
- iPhone Safari 優先

## できること

1. **人格調律**：人格項目（23軸）はすべて任意。最上部の一覧か各カテゴリの中で使う項目にチェックを入れ（新規は全項目OFFから）、選んだ項目だけを 5段階のスライダーで調整する。使っていない項目は控えめな色の行で並び、いつでもチェックできる（外しても値は残る）。「初期」「信頼成立後」「関係深化後」を設定し、変えたくない軸は固定できる。口調プリセット（8種）と一人称・二人称も設定。
2. **人格プリセット**：基本人格12種（高慢・尊大、クーデレ、ツンデレなど）と愛情スタイル8種（甘々、溺愛、無口な溺愛など）。適用前に「今の値 → 提案」を確認でき、使用中で値が違う項目は既定で今の値を残す。固定中の項目は変えない。基本人格と愛情スタイルは別の項目を変えるので重ねて使える。関係での変わり方（徐々に軟化／大きなギャップ／変化は控えめ）を選べ、直前の適用は取り消せる。
3. **関係段階の作り方**：自動提案（初期から後の2段階を一度だけ提案）／連動調整（初期を動かすと段階差を保って追従）／完全個別。
4. **関係・反応**：信頼が成立する／深まる／後退する条件、恋愛感情（信頼とは別軸）、If-Then の行動規則。
5. **人格の試着**：12の状況で、3段階の会話例を並べて比較。口調・呼称を試しに変えられる。会話例は Markdown で書き出せる。
6. **Markdown出力**：予定文字数に合わせて詳細度を自動選択。共通部分は一度だけ、段階の変化は差分で書く。出力するのは選んだ人格項目だけ。プリセット名は標準では出さず、今の値から作った行動規則を出力する。
   - 出力する節を選べる：話し方・呼称／基本人格・核・3段階の振る舞い／関係の進展条件（初期→信頼成立後・信頼成立後→関係深化後・後退の3種を個別に）／恋愛感情の条件・反応／If-Then（規則ごとにも選択）。新規は話し方と人格だけON。OFFでも設定は保持する。
   - 未設定の行（条件0件など）や空の見出しは出力しない。各節の横に、今の詳細度での増減字数を表示する。

## 愛情の示し方（v0.4で4軸に分割）

| 軸 | 内容 | 区別する項目 |
|---|---|---|
| 言葉による愛情表現 | 好意や感謝を言葉にする度合い | 行動による愛情表現 |
| 行動による愛情表現 | 手助けや気遣いで示す度合い | 言葉による愛情表現 |
| 甘やかし度 | 相手を喜ばせ、世話を焼く度合い（相手の意思や自立は無視しない） | 甘え・頼り方（自分が相手に頼る） |
| 特別扱い | その相手にだけ態度を変える度合い | 独占志向・嫉妬の表出 |

恋愛感情を持たない設定では、親愛・友情の範囲として出力します。どの軸も触れ方（身体の距離）は強めません。

## 使い方

画面右上の「使い方」から、手順とコツを確認できます。

1. 予定文字数を決める
2. 使う人格項目を選ぶ（またはプリセットから始める）
3. 口調と呼称を決める
4. 段階（初期／信頼成立後／関係深化後）ごとにスライダーで調律し、変えない芯は固定する
5. 関係・反応の条件を決める
6. 人格の試着で会話例を確かめる
7. Markdownを出力して、AIチャットのキャラクター設定欄に貼る
8. ときどきJSONで控えを取る

## データの互換性

- v0.1〜v0.3 のJSON・ブラウザ保存データを読み込めます。ブラウザ保存の旧データは、移行前の内容を別名で控えてから変換します。
- v0.3 の「愛情表現」は、言葉・行動の2軸へ推定で変換し、使用・固定・優先度を引き継ぎます（意味が完全に一致するとは限りません）。甘やかし度と特別扱いは初期値・未使用です。元の値はデータ内（`legacy.affection`）に残します。
- v0.3 以前のデータは「完全個別」で引き継ぎ、自動提案や連動は有効にしません。
- v0.4 以前のデータは、出力する節・種類・If-Then規則をすべてONで引き継ぎます（v0.4.1から「（未設定）」の行は出力しません）。

## 注意

- 創作支援のためのツールで、心理検査ではありません。
- 会話例は外部AIを使わない簡易プレビュー（テンプレートの組み合わせ）です。組み合わせによっては不自然な言い回しになることがあります。
